# Git 练习仓库

这个仓库是人为构造的，用来观察 分支、合并、冲突 在图形界面里长什么样。

## 历史结构

| 分支 | 状态 | 说明 |
|---|---|---|
| main | 主线 | 所有合并最终汇到这里 |
| feature/login | 已合并 | 产生第 1 个合并点 |
| fix/typo | 冲突后合并 | 产生第 2 个合并点，合并时真的冲突过 |
| experiment | 未合并 | 故意留着，用来对比分叉 |

## 建议练习

1. 在 Git Graph 里找到两个合并点（有两条线汇入的圆点）
2. 点开合并提交，右侧会显示它有两个父提交
3. 对比 experiment 分支的起点和 main 的走向
4. 右键任意提交，试试 Checkout 和 Create Branch
